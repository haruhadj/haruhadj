## 🧭 How I Build with AI

| I do | AI helps with |
| :--- | :--- |
| Define requirements, architecture, and data models | Scaffolding, boilerplate, multi-file refactors |
| Design schemas and API contracts (Zod, Drizzle) | Implementing against those contracts |
| Review diffs, test behavior, check security | Catching lint/build errors and self-correcting |
| Decide what ships and what gets thrown out | Exploring codebases and explaining unfamiliar code |

### Agentic Workflows
- **Codebase navigation:** map file relationships and run multi-file refactors with Claude Code.
- **Autonomous fix loops:** let the toolchain catch lint/build errors and self-correct.
- **Native tooling:** drive Git, branches, and PRs from the CLI via natural language.
- **Containerized pipelines:** Docker for parity between local AI workflows and prod.
- **Guardrails:** strict schemas (`CLAUDE.md`, Zod) keep agentic actions predictable.
- **Human in the loop:** nothing merges without my review.
